 **Goal :** 

Understand how to build a complete CRUD REST API using `@RestController`, `@GetMapping`, `@PostMapping`, `@PutMapping` and `@DeleteMapping`, and how to return the correct HTTP status codes, including a `400 Bad Request` for invalid input. Data is stored in an in-memory `ArrayList` (no database).

 **Available Endpoints** 
The following endpoints need to be implemented in the application:

- Get all books

```
GET /api/books

```

- Get book by ID

```
GET /api/books/{id}

```

- Add a new book

```
POST /api/books

```

- Update an existing book

```
PUT /api/books/{id}

```

- Delete a book

```
DELETE /api/books/{id}

```

 **Book Details :** 

Field	Type	Description
id	int	Unique book ID (auto-generated, starting from 1)
title	String	Title of the book
author	String	Author of the book
price	double	Price of the book

 **Your Task :** 

- Use an in-memory ArrayList<Book> to store the books. Do not use any database.
- Create a Book class with the fields above, a default constructor, and getters and setters.
- Use @RestController for the controller class, with base path /api/books.
- Implement all 5 endpoints using the matching annotations: @GetMapping, @PostMapping, @PutMapping and @DeleteMapping.
- Use @PathVariable to read the id from the URL and @RequestBody to read the book data from the request body.
- The id must be generated by the application (1, 2, 3,...). Ignore any id sent in the request body.
- A book must have a non-empty title. If the title is missing or blank, do not save the book.
- Return the following HTTP status codes:
Endpoint	Scenario	Status Code	Response
`GET /api/books`	Always	`200 OK`	List of all books
`GET /api/books/{id}`	Book found	`200 OK`	The book
`GET /api/books/{id}`	Book not found	`404 Not Found`	"Book not found"
`POST /api/books`	Book created	`201 Created`	The created book with its generated ID
`POST /api/books`	Title missing or blank	`400 Bad Request`	"Title is required"
`PUT /api/books/{id}`	Book updated	`200 OK`	The updated book
`PUT /api/books/{id}`	Book not found	`404 Not Found`	"Book not found"
`PUT /api/books/{id}`	Title missing or blank	`400 Bad Request`	"Title is required"
`DELETE /api/books/{id}`	Book deleted	`200 OK`	"Book deleted successfully"
`DELETE /api/books/{id}`	Book not found	`404 Not Found`	"Book not found"
