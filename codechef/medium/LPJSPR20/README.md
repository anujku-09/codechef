## Problem

### Print Squares

Write a program to output the squares (using multiplication) of numbers from 1 to 5 on separate lines.

[ **Note:**  Print the output in the same format as given below.]

### Sample 1:
Input
Output

```

```

```
1 - 1

```

## Solution

**Language:** JavaScript  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-06T19:04:30.680Z  

```js
// your code goes here
console.log("1 - " + (1 * 1));
console.log("2 - " + (2 * 2));
console.log("3 - " + (3 * 3));
console.log("4 - " + (4 * 4));
console.log("5 - " + (5 * 5));
```
