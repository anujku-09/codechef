## Problem

### EventMaster - Digital Ticket Verification System
- EventMaster is moving from paper tickets to digital tickets using JSON Web Tokens (JWTs).
- Each ticket: Is generated by signing attendee details into a JWT Must be verified before allowing entry to an event
- Your task is to implement the logic to generate and verify digital tickets.

 **Function Requirements** 

 **1.generateTicket(attendeeId, eventName)** 
This function must:

- Create a JWT payload containing: attendeeId eventName
- Sign the JWT using the provided secret key
- Set the token to expire in 24 hours
- Return the generated JWT as a string

 **2.verifyTicket(ticket)** 
This function must:

- Verify the given JWT using the same secret key
- If the ticket is valid: Return the decoded payload
- If the ticket is invalid or expired: Return null

Use `try-catch` to handle verification errors.
